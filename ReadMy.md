# Настройка VPS сервера
**Основной канал:** VLESS + Reality (TCP, порт 443)  
**Резервный канал:** Hysteria2 (UDP, порт 8443)

**Данные пользователей хранятся:** `/opt/vps-manage/users/`

## 📁 Структура репозитория
```
git@github.com:Supermaks777/vps.git
├── src/
│ ├── create_server.sh # Первичная установка сервера
│ ├── xray-user-add.sh # Добавление пользователя
│ ├── xray-user-del.sh # Удаление пользователя
│ └── xray-user-list.sh # Список пользователей
└── README.md # Эта инструкция
```

## 🚀 Первичная настройка сервера (выполняется один раз)
### 1. Подключаемся как root

* ssh root@адрес_сервера

### 2. создаем пользователя и добавьте в sudo
* useradd -m -s /bin/bash my_user

### 3. Устанавливаем пароль
* passwd my_user

### 4. Добавляем в группу sudo
* usermod -aG sudo my_user

### 5. Копируем SSH-ключи (если добавляли при создании сервера)
* mkdir -p /home/my_user/.ssh
* cp /root/.ssh/authorized_keys /home/my_user/.ssh/ 2>/dev/null
* chown -R my_user:my_user /home/my_user/.ssh
* chmod 700 /home/my_user/.ssh
* chmod 600 /home/my_user/.ssh/authorized_keys 2>/dev/null

### 6. Заходим под новым пользователем
* exit
* ssh my_user@адрес_сервера

### 7. Выполняем скрипт с гитхаба (скачивает нужные скрипты, устанавливает алиасы) и применяем
* bash <(curl -fsSL https://raw.githubusercontent.com/Supermaks777/vps/main/src/install_all.sh)
* source ~/.bashrc

### 8. Запускаем создание сервера
* vps-setup

### 9. Получаем токен телеграмм бота
* Ищем `@BotFather` в Telegram (с синей галочкой — официальный аккаунт)
* Пишем команду /newbot
* Придумываем уникальное имя бота (`username`) — должно заканчиваться на bot
* Копируем полученный токен (он выглядит примерно так: 1234567890:ABCdefGHIJKLMNopQRStUVWXYZ-abcde)

### 10. Получаем User ID в телеграмме
* ищем телеграмм-бота `@userinfobot`
* пишем команду `/start`
* получаем цифровой `user_id`

### 10. Запускаем создание телеграмм бота
* vps-create-bot <ТОКЕН_ТЕЛЕГРАММ_БОТА> <`user_id`>


# 👥 Управление пользователями (через терминал)

| Действие | Команда | Пример | Что произойдёт |
|----------|---------|--------|----------------|
| **Добавить пользователя** | `vps-add <имя_пользователя>` | `vps-add papa` | • Проверка, что пользователь не существует в Xray и Hysteria2<br>• Генерация UUID для VLESS<br>• Генерация случайного пароля для Hysteria2<br>• Добавление в конфиг Xray<br>• Добавление в конфиг Hysteria2<br>• Создание файла `/opt/vps-manage/users/имя.txt`<br>• Вывод готовых ссылок для клиента |
| **Список пользователей** | `vps-list` | `vps-list` | • Показывает всех пользователей из конфига Xray<br>• Показывает файлы пользователей в директории |
| **Удалить пользователя** | `vps-del <имя_пользователя>` | `vps-del papa` | • Удаление из конфига Xray<br>• Сброс пароля в Hysteria2<br>• Удаление файла пользователя<br>• Перезапуск сервисов |
| **Данные пользователя** | `vps-show <>` | `vps-show papa` | • Отображение на экране данных пользователя (строки для подключения) |

## 🔒 Дополнительные настройки клиента (v2rayNG)

Эти настройки повышают скрытность и защищают от обнаружения шпионскими приложениями.
### 1. Сменить порт локального прокси

| Действие | Значение |
|----------|----------|
| **Почему** | Избежать сканирования стандартного порта `10808` |
| **Что делать** | Настройки → «Порт локального прокси (SOCKS5)» → установить `59431` (или любой в диапазоне `49152–65535`) |

### 2. Включить аутентификацию на локальном прокси

| Действие | Значение |
|----------|----------|
| **Почему** | Приложение-шпион не сможет подключиться к прокси без пароля |
| **Что делать** | Настройки → «Пользователь локального прокси» → включить, задать логин и пароль (запишите в менеджер паролей). Доступно с версии **v2rayNG 2.1.0** |

### 3. Включить фрагментацию

| Действие | Значение |
|----------|----------|
| **Почему** | Разбивает TLS-приветствие на мелкие части, затрудняя анализ DPI |
| **Что делать** | Настройки → «Фрагментация» → включить<br>**Пакеты:** `tlshello,1-5`<br>**Длина:** `10-100`<br>**Интервал:** `1-5` |

### 4. Использовать TUN-режим (VPN), а не прокси

| Действие | Значение |
|----------|----------|
| **Почему** | TUN-режим не создаёт открытых портов на `127.0.0.1`, которые могут сканировать шпионские приложения |
| **Что делать** | В настройках убедиться, что выбран «Режим VPN». При подключении должно появляться разрешение на создание VPN-соединения. В версии 2.0.13+ используется Xray Native TUN |

### 5. Настроить маршрутизацию по приложениям (Per-App Proxy)

| Действие | Значение |
|----------|----------|
| **Почему** | «Чистые» приложения (Сбер, Озон, банки) можно отправить в обход VPN, чтобы они не жаловались на «необычный трафик» |
| **Что делать** | Настройки → «Per‑app proxy» → включить Bypass mode → отметить приложения, которые должны идти напрямую |

## ⚠️ Важно

- После изменения порта не забудьте обновить настройки в **SwitchyOmega** (Windows) или в приложениях, которые используют прямой SOCKS5.
- Аутентификация работает только с версии **v2rayNG 2.1.0** (апрель 2026) и новее.
- Фрагментация может слегка увеличить задержку. Если заметите проблемы со стабильностью — отключите.
- Рекомендуется периодически проверять обновления клиентов на официальных GitHub-репозиториях.

# 🔧 Полезные команды

| Команда | Описание |
|---------|----------|
| `vps-setup` | Первичная установка сервера |
| `vps-add <имя>` | Добавить пользователя |
| `vps-list` | Список пользователей |
| `vps-del <имя>` | Удалить пользователя |

## Проверка статуса сервисов
* sudo systemctl status xray
* sudo systemctl status hysteria-server

## Просмотр логов
* sudo journalctl -u xray -f
* sudo journalctl -u hysteria-server -f
# ⚠️ Важные замечания
* **Не запускайте скрипты от root** — используйте пользователя с sudo
* Сохраняйте ссылки в надёжном месте (менеджер паролей)
* После vps-del все клиенты пользователя потеряют доступ
* Публичный репозиторий — ссылки видны всем, но ключи генерируются на сервере
* **Hysteria2 использует самоподписанный сертификат** — клиент может выдавать предупреждение

# 🆘 Возможные проблемы

| Проблема | Решение |
|----------|---------|
| `User already exists` | Пользователь с таким именем уже есть — выберите другое имя |
| `Connection refused` | Проверьте статус сервисов: `sudo systemctl status xray hysteria-server` |
| `Permission denied` | Запускайте скрипты с `sudo` или через алиасы (`vps-add`, `vps-list` и т.д.) |
| `vps-add: command not found` | Алиасы не добавлены — выполните `source ~/.bashrc` или перезайдите в сессию |
| `SSL certificate error` (Hysteria2) | Самоподписанный сертификат — в клиенте включите `allow insecure` или `skip verify` |
